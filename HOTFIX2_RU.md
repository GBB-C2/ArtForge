# ArtForge Studio 0.48.3 HOTFIX2

Исправления и проверка от 6 ноября 2026 года. Архив содержит полный проект с исходниками. Версия пакетов 0.48.3 и схема проектов 43 сохранены.

## Исправлено

| Проблема | Изменение | Проверка |
|---|---|---|
| Экспорт и миниатюры могли бесконечно ждать ответа GPU при чтении кадра; отмена не проверялась внутри ожидания | Неблокирующий опрос, проверка отмены, тайм-аут 120 секунд и освобождение буфера при ошибке. Поток миниатюр получает общий сигнал остановки | Тесты успешного завершения, отмены до и во время опроса, отсутствующего callback, ошибки и разрыва канала |
| Переключение кинематографичного взрыва могло оставлять источник и симуляцию от прежнего пресета | Признак `cinematic_blast` включён в ключ кэша FX | Регрессия меняет только этот признак и проверяет новый ключ и конфигурацию |
| После привязки FX к мешу нельзя было прокрутить инспектор до расчёта и столкновений | Высота панели учитывает все настройки выбранного FX/вспомогательного объекта | Проверка доступности очистки кэша и переключателя столкновений после привязки |
| Встроенная сцена «Ателье орбит» не открывалась из-за старой версии данных и сглаживания 2× | Встроенные данные проходят тот же путь миграции и валидации, что и файлы; пример и генератор используют допустимое сглаживание 4× | Валидация, расчёт пяти моментов анимации, фоновый импорт и Undo; совпадение генератора с сохранённым примером |
| Повторные разрезы меша создавали вырожденные грани, незамкнутые рёбра и неверный материал на почти коллинеарных участках | Допуск триангуляции учитывает размер контура и точность координат; общие вершины свариваются; незамкнутый разрез отбрасывается и выбирается следующая плоскость | Куб до 32 осколков, сфера и вогнутая геометрия; замкнутость, объём, повторяемость, материалы и отмена |
| После JSON-сохранения и открытия менялась последняя цифра времени отдельных ключей анимации | Для `serde_json` включён `float_roundtrip`, версии зависимостей не изменены | Точное сравнение проекта после сериализации/десериализации, включая записанную анимацию осколков |
| Набор Rust-тестов не компилировался и содержал устаревшие UI-сценарии | Исправлены отсутствующие импорты, подготовка тестовых сцен, ожидание фоновых задач, актуальные пункты меню/секции и допуски округления | Полный набор тестов проходит; существующие тесты не удалены и не переведены в `ignored` |

## Результаты

- **Rust:** 1283 пройдено, 0 ошибок, 74 проверки с ранее установленным `ignored` пропущены.
- **Python:** 62 пройдено, 0 ошибок.
- **Windows x64:** `cargo check --workspace --all-targets --locked --target x86_64-pc-windows-msvc` завершён успешно. Остались предупреждения о неиспользуемом коде/импорте.
- **WGSL:** обе CPU-проверки шейдеров Naga прошли в составе Rust-тестов.

Полный Rust-прогон выполнен на Linux с закреплённым Rust 1.99.1. Для сокращения времени сборки приложения и совместимости линковщика этой среды использовались локальные переопределения профиля тестов; файлы профилей проекта не менялись:

```sh
cargo test --workspace --locked --no-fail-fast \
  --config profile.test.package.artforge.opt-level=0 \
  --config profile.test.package.poseforge-io.codegen-units=1
python -m unittest discover -s scripts -p 'test_*.py'
python scripts/source_audit.py
```

## Запуск и оставшаяся аппаратная проверка

Распакуйте архив в отдельную папку и запустите `START_WINDOWS.cmd`. Он собирает свежие исходники и запускает результат. Требуются Rust 1.99.1 и C++ Build Tools, как описано в `START_HERE_RU.md`.

Готовый Windows EXE в этот архив не входит. Проверка Windows-кода не заменяет запуск приложения: окно, аппаратный рендер, работа конкретного драйвера и FPS здесь не проверялись. Пропущенные GPU/нагрузочные тесты не считаются пройденными. Тайм-аут защищает ожидание callback чтения кадра; он не является гарантией восстановления зависшего графического драйвера. Кадр, который действительно рассчитывается дольше 120 секунд, потребует меньшего разрешения или сложности сцены.

На машине с видеокартой можно выполнить существующую проверку материалов:

```powershell
powershell -ExecutionPolicy Bypass -File scripts/verify-materials.ps1 -Gpu
```

Для проверки исправлений в интерфейсе откройте «Ателье орбит», привяжите FX к мешу и прокрутите до настроек столкновений, переключите обычный/кинематографичный взрыв, проверьте отмену экспорта и повторное открытие сцены с анимацией.
