# ArtForge Studio 0.48.3 HOTFIX4

Изменение панели материалов от 6 ноября 2026 года.

- Удалены разделы **«Художественная поверхность»** и **«Микрорельеф и лепка»**, включая переключатели, выбор типа, общий сброс и семь полей микрорельефа.
- Убрано освободившееся место. Раздел «Краска и бумага» расположен сразу после остальных настроек материала; высота прокрутки пересчитана.
- Сохранённые флаги сворачивания удалённых разделов не скрывают оставшиеся настройки. Изменения не обнуляют данные материалов в существующих проектах.
- Обновлено руководство по материалам. Архив включает все исправления HOTFIX3.

Проверено на итоговых исходниках:

| Проверка | Результат |
|---|---|
| Материалы: доступность полей, редактирование, валидация, Undo/Redo и отсутствие удалённых разделов | 19 Rust-тестов пройдено |
| Разметка, сворачивание разделов и прокрутка | 10 Rust-тестов пройдено |
| Python-проверки проекта | 62 теста пройдено |
| Windows x64, весь workspace и все цели | `cargo check --workspace --all-targets --locked --target x86_64-pc-windows-msvc` прошёл |
| Статический аудит исходников | 316 Rust, 10 WGSL, 228 связей модулей, 20 JSON-примеров; 0 ошибок |

Полный набор Rust-тестов в этом изменении повторно не запускался. Аппаратный рендер и Windows GUI здесь не проверялись. Логи: [материалы](docs/validation/hotfix4-material-tests.txt), [разметка](docs/validation/hotfix4-layout-tests.txt), [Python](docs/validation/hotfix4-python-tests.txt), [Windows](docs/validation/hotfix4-windows-check.txt), [аудит](docs/validation/hotfix4-source-audit.json).

Архив содержит полный проект с исходниками, без готового EXE. Для сборки и запуска на Windows используйте `START_WINDOWS.cmd`; требования описаны в `START_HERE_RU.md`.
