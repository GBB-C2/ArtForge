# ArtForge

3D-редактор на Rust: моделирование, процедурные модификаторы, материалы, скелеты и анимация.

## Запуск

Нужен Rust; на Windows — также C++ Build Tools (MSVC).

На Windows скачайте и распакуйте проект, затем запустите `START_WINDOWS.cmd`. Скрипт соберёт приложение из исходников.

Или выполните в папке проекта:

```sh
cargo run -p artforge --release --locked
```
