# Начало работы

## Сборка и запуск

1. Установите Rust. Нужная версия указана в [rust-toolchain.toml](rust-toolchain.toml).
2. На Windows установите C++ Build Tools (MSVC).
3. Скачайте репозиторий через **Code → Download ZIP** и распакуйте целиком.
4. На Windows запустите `START_WINDOWS.cmd`. При первой сборке загружаются зависимости.

Запуск из терминала в папке проекта:

```sh
cargo run -p artforge --release --locked
```

## Первые шаги

- **Проект** — открыть, импортировать или сохранить сцену.
- **Меш / Кривые / Скелет / Свет** — добавить объект.
- Выберите объект в сцене, чтобы открыть его свойства справа.
- Вкладка **Модификаторы** — добавить зеркало, массив, подразделение или толщину.
- Строки модификаторов можно переставлять и переносить на другой меш; **Ctrl + перенос** создаёт копию.

| Действие | Клавиши |
|---|---|
| Перемещение / вращение / масштаб | G / R / S |
| Редактирование геометрии | F2 |
| Вписать выбранное в кадр | F |
| Отмена / повтор | Ctrl+Z / Ctrl+Y |
| Подтвердить / отменить ввод | Enter / Esc |

Для импорта `.blend` нужен установленный Blender. GLB, glTF, OBJ и проекты открываются без него.
