# Камера, свет и меш на кривой

Создайте кривую через верхнее меню «Кривые» или нарисуйте её. Затем выделите меш, камеру либо источник света, откройте «Объект» и прокрутите до раздела **«Привязка к кривой»**. Выберите кривую из списка или нажмите пипетку справа от него и щёлкните по линии кривой в просмотре либо по её строке в списке сцены. Одну кривую можно использовать для нескольких объектов; геометрия трубки или ленты ей не обязательна.

Пипетка сохраняет выделение исходного объекта. Клик по пустому месту или объекту другого типа оставляет её активной; Esc, правая кнопка и повторное нажатие пипетки отменяют выбор. Клик по другой кнопке интерфейса закрывает пипетку без выполнения той кнопки. Скрытые и заблокированные кривые в просмотре не подбираются. Кривая с геометрией показывает исходную линию во время выбора. Если кривых в сцене нет, пипетка отключена. Успешное назначение отменяется одним Undo; неподходящая или циклическая связь не меняет проект.

При первой привязке базовые перемещение и поворот объекта сбрасываются относительно пути; масштаб меша сохраняется. Если время сцены равно нулю, объект начинает с начала кривой. Существующие ключи трансформации становятся смещениями относительно пути.

| Настройка | Действие |
|---|---|
| Положение, % | Положение на длине кривой при нулевом времени: 0 — начало, 100 — конец. |
| Скорость, %/с | Перемещение по времени сцены. 10 %/с — полный проход за 10 секунд; 0 — неподвижная привязка. Отрицательное значение меняет направление. |
| Поворот по кривой | Поворот по касательной. Камера и свет смотрят вдоль −Z, меш ориентируется вдоль +Z. При отключении путь меняет только положение. |
| Повторять движение | После конца возвращает в начало. Для непрерывного движения используйте замкнутую кривую. При выключении объект останавливается на конце. |
| Edit | Включает свободное перемещение от кривой обычным гизмо X/Y/Z и его центром. Повторное нажатие возвращает движение вдоль пути. |
| Сброс рядом с Edit | Обнуляет отступ от пути. Процент пути, скорость, повтор, поворот, масштаб и цель света сохраняются. |
| Кривая | Выделяет исходную кривую для изменения её формы. |
| Отвязать | Убирает связь и фиксирует рамку пути на текущем кадре; сохраняет положение и пересчитывает ключи смещения. |

Ползунки поддерживают двойной щелчок для точного ввода, Shift для точной протяжки и кнопку сброса. Скорость ползунком задаётся в диапазоне −100…100 %/с, точным вводом — до ±10000 %/с. Положение и скорость можно менять независимо. При включённом повторе 100 % совпадает с началом.

Нажмите пробел для воспроизведения или перемещайте время на шкале. Положение вычисляется по длине кривой после её трансформации, поэтому растянутая кривая не меняет равномерность скорости на разных участках. Сама кривая и её родители могут быть анимированы. Точность следования ограничена детализацией исходной кривой.

С 0.47.21 инструмент G перемещает привязанные меш, камеру, свет и пустышку **вдоль кривой**, пока Edit выключен: перетаскивание центра или оси гизмо меняет «Положение, %». Заданные смещение, поворот, масштаб, скорость и слежение света сохраняются. В виде камеры с включённым управлением камерой панорамирование проецирует перемещение на путь, а колесо и лупа продвигают камеру вдоль него, даже если она смотрит поперёк пути. Esc отменяет жест, Ctrl+Z — завершённое перемещение. Возврат мыши в начало жеста не создаёт лишний шаг истории.

Числовые XYZ камеры задают локальный отступ от пути. Поля положения и направления света показывают мировые координаты и пересчитываются в отступ. Поворот R и масштаб S сохраняют прежнее действие. При групповом перемещении ограничения привязанных объектов сохраняются; если в том же выделении движется исходная кривая или её родитель, объект следует за источником без второго смещения. Edit относится к активному объекту.

Для свободной расстановки нажмите **Edit**. Редактор останавливает проигрывание и включает режим «Сцена»: гизмо меняет базовое смещение относительно пути, не переписывая существующие ключи. Время шкалы и выбранный клип сохраняются; при возврате к анимации снова учитываются её ключи. Привязка и процент пути не меняются, а в просмотре видны акцентная кривая, точка на ней и линия отступа. Повторный Edit или Esc без активного жеста выключает режим. Смена объекта, вкладки свойств, режима редактора или потеря фокуса тоже закрывает Edit; сам отступ остаётся в проекте.

Иконка сброса справа от Edit возвращает объект на путь в текущей точке времени. Она не отвязывает объект и не ставит «Положение, %» в ноль. Если отступ уже нулевой, иконка приглушена, без фона и обводки; повторный сброс не добавляет историю. Отдельное нажатие сброса и завершённый жест отменяются через Undo. При перетаскивании Esc отменяет только этот жест; следующий Esc выключает Edit.

На ненулевом времени учитывается скорость: меняется начальное положение, а не скорость. Если движение без повтора уже упёрлось в конец, доступный диапазон ограничен существующими параметрами; для ручной расстановки можно вернуться к началу времени или установить скорость 0. Для повторяющегося открытого пути перетаскивание к последней точке приближает объект к концу без скачка в начало.

Слежение света за выбранным объектом имеет приоритет над направлением касательной. Скройте исходную кривую в сцене, если не нужны её вспомогательные линии: привязка продолжит работать.

Связь не делает объект дочерним кривой. При удалении отдельной кривой или превращении её в меш привязанные к ней отдельные объекты остаются в текущем положении. Undo восстанавливает исходную связь. Обычные правила удаления реальных дочерних объектов в иерархии остаются в силе. Циклы зависимостей отклоняются. Отвязка, которая не может сохранить трансформацию из-за неравномерного масштаба родителя, отклоняется целиком; для анимированного объекта требуется равномерный масштаб родителя.

Привязки сохраняются в **.artforge** и учитываются при рендере кадров. Перенос такого ограничения в glTF/OBJ не реализован: для дальнейшего редактирования сохраняйте исходный проект. [Пример](../examples/curve-follow.artforge) содержит общий путь, движущийся меш, камеру и прожектор, следящий за мешем.
