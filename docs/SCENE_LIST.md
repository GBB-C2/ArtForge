# Список сцены

В 0.34.0 под материалами объекта добавлена строка «Жидкость» с собственной иконкой. Щелчок открывает её параметры, глаз скрывает поверхность, крестик снимает жидкость с примитива. Обе операции поддерживают Undo. Материал, исходный меш и дочерние объекты сохраняются.

С версии 0.33.0 щелчок по пустому месту списка снимает выделение. У назначенного материала глаз скрывает/показывает все поверхности с этим общим материалом; крестик снимает его назначение только с данного объекта. Другие материалы, экземпляры меша и библиотечный материал сохраняются. Обе операции можно отменить.

В поисковой строке нажмите значок фильтра. Флажки «Меши», «Кости», «Освещение» и «Камеры» переключаются независимо; меню остаётся открытым до Escape или щелчка снаружи. Клавиши ↑/↓ выбирают строку, пробел переключает флажок. Поиск работает вместе с фильтром. Родительские узлы сохраняются для понимания иерархии.

Глазок управляет видимостью. Крестик рядом удаляет соответствующий объект или свет; Ctrl+Z возвращает удалённое. Удаление папки оставляет её содержимое в сцене. Отдельного флажка «Видимость» под списком больше нет. Используемую skin кость нельзя удалить отдельно от персонажа.

Стрелка у примитива раскрывает назначенные материалы с миниатюрами. Щелчок по материалу открывает его параметры в разделе «На объекте». Библиотека материалов остаётся отдельной.

- Потяните материал выше или ниже другого материала того же примитива — изменится только порядок списка, назначения на полигоны сохранятся.
- Перенесите его на другой примитив — материал назначится всему этому примитиву.
- Перенесите на строку материала другого примитива — заменится только это назначение; остальные материалы и грани сохранятся.
- Исходный примитив сохраняет свой материал. Общие экземпляры меша изолируются при необходимости, чтобы не изменить остальные объекты. Перенос из библиотеки в список сцены также поддерживается.

Кнопка папки в заголовке создаёт папку с текущим выделением и предлагает название. Без выделения создаётся пустая папка. Источники света тоже можно помещать в папки. Переименование и перенос через меню «…» доступны без перетаскивания.

Строки перетаскиваются мышью: линия показывает место вставки, рамка папки — перенос внутрь. Для выхода из папки используйте свободное место внизу списка либо меню «… → Переместить в папку… → Без папки». У верхнего и нижнего края список прокручивается автоматически. Escape, потеря фокуса или отпускание вне допустимого места отменяют перенос. Перемещение фиксируется одним шагом Undo после отпускания мыши.

Папки располагаются на верхнем уровне. Соседние объекты одной иерархии можно переставлять; перенос в папки не меняет родителей, мировые трансформации или связи скелета. Ветку, наследующую папку от родителя, выносят вместе с родительским объектом. Заблокированные объекты и папки защищены от перемещения и удаления.

Порядок объектов, порядок материалов и состав папок сохраняются в `.artforge` (схема 17). Старые схемы 1–16 загружаются с прежним порядком и без новых ограничений на исходную геометрию.
