# Проверка ArtForge Studio 0.48.3

## Список эффектов камеры

Пройдены 20 проверок интерфейса камеры и 5 тестов настроек: добавление без дублей, выбор строк, глаз, сброс, удаление, Undo/Redo, сохранение, старые проекты, блокировка камеры и отмена меню. Проверены обе темы, малое окно и DPI 100/200%. Кнопка FX снова открывает меню четырёх объёмных эффектов.

Отдельный тест Vulkan/llvmpipe подтвердил изменение изображения, сохранение альфа-канала PNG и точное восстановление исходного кадра при выключении всех строк или общего переключателя. Исправление видимости объёмных FX из предыдущего изменения сохранено.

В нативном Linux-окне проверены меню FX, добавление виньетки и зерна, открытие поля по Enter, выключение строки пробелом, удаление и Undo, закрытие меню по Esc и смена темы без потери настроек. Снимки: [тёмная тема](previews/camera-effects/dark.jpg), [светлая тема](previews/camera-effects/light.jpg), [выпадающее меню](previews/camera-effects/dropdown.jpg). Использован программный Vulkan и растровый предпросмотр; тестовые изменения сцены отменены.

Нативная сборка Linux и `git diff --check` проходят. Полный workspace-набор, Windows GUI, аппаратный GPU и FPS в этой проверке не запускались. `cargo fmt --all --check` ранее обнаружил расхождения форматирования в репозитории; массовое переформатирование не выполнялось.

## 0.48.2 — новый взрыв из референса

**Проверено в среде:** статический аудит исходников (0 ошибок; 220 обнаруженных модулей Rust, 9 WGSL-файлов), соответствие пяти workspace-версий `0.48.2`, связка нового пресета с CPU-полями, рендером и меню. В отдельном численном приближении формы лобов, шапки и пылевого кольца есть ненулевые ячейки для сеток 16³, 24³ и 32³. Эти проверки **не** запускают сам Rust-решатель и не подтверждают картинку на GPU.

**Добавлены Rust-регрессии, запуск требуется:** сериализация новых полей со старыми проектами без `cinematic_blast`, четвёртый пресет огня и сохранение остальных 12, Undo в панели, начальная форма и дым/пламя с воспроизводимым checkpoint, наличие флага шейдера в пакете FX. Вариант с несжимаемым давлением не симулирует физическую ударную волну, а искры не являются частицами с коллизиями.

**Не удалось проверить здесь:** сборка `cargo check`/`cargo test`, синтаксическая проверка WGSL через Naga, запуск GUI на Windows, GPU-изображение и FPS — компилятор Rust и видеокарта недоступны. Попытки прогнать полную библиотеку вспомогательных Python-тестов прерывались по тайм-ауту, поэтому не считаются успешными. Результат следует проверить на машине с Rust 1.99, отдельно с качеством 16³ и 32³.

Рекомендуемые команды после распаковки:

```sh
cargo check --workspace --all-targets --locked
cargo test -p poseforge-core fx --locked

cargo test -p artforge fx_controls::tests --locked
```

В приложении: **FX → Огонь → Пресеты… → Кинематографичный взрыв**. Проверить первые 0.1–1.5 секунды на чёрном фоне, дым после 2–4 секунд, затем экспорт и перемотку назад; на слабой машине сперва выбрать «Быстро». Сравнить с обычным «Огненным взрывом» и старой сохранённой сценой.

Отдельно проверена геометрическая поддержка источника меньше ячейки. Это проверки формул в NumPy, не выполнение Rust-решателя и не замер FPS.

## 0.47.0 — предыдущий выпуск

- 36 Python-тестов: аудит исходников, стартовый персонаж и экспорт Blender. Все завершились успешно.
- Статический аудит исходников, путей модулей, ресурсов, манифестов Cargo и JSON-примеров. Результат сохраняется отдельно в отчёте упаковки. Это проверка структуры, не компиляция.
- Проверены изменения относительно полного архива 0.45.0: исходные файлы сохранены, добавлены модуль фоновой лучевой геометрии и тест миграции физики. Посторонние файлы и временные кэши в архив не включаются.
- Проверка ZIP: CRC, безопасные пути, точное побайтовое совпадение с рабочими исходниками и локальные ссылки Markdown.
- Пять локальных пакетов имеют версию 0.46.0. Реестровые версии, источники и контрольные суммы Cargo.lock не изменялись; прямая зависимость приложения от serde сохранена.

## Не запускалось

В среде нет Rust, Cargo, rustfmt и Blender. Компиляция, Rust-тесты, Clippy, WGSL/Naga, нативный интерфейс, Windows EXE и GPU не запускались. Реальные FPS, задержки кадров и расход памяти не измерялись. Исправления причин задержек основаны на анализе кода. Архив содержит исходники, не готовый EXE.

## Подготовленные регрессии Rust — не запускались

Добавлены 23 проверки поведения:

- Ткань: отменённый шаг не меняет завершённое состояние, расчёт можно продолжить; мягкие ограничения не раздвигают UV-копии; общие нормали и закрепление; обновление дерева контактов соответствует свежему дереву.
- Рабочие потоки ткани: разорванный канал освобождает ожидание; заполненная очередь не блокирует отправителя; сброс отбрасывает устаревшую ошибку и сохраняет время новой заявки.
- Жидкость: частая перемотка оставляет ограниченную очередь, разрыв канала не оставляет вечного ожидания; квота поверхностей освобождается по окончании работы; будущая поверхность и неверные параметры не публикуются; предел финальной детализации независим от интерактивного.
- Поверхность жидкости: одинаковый шаг даёт одинаковую геометрию в предварительном и финальном режиме, сохраняются отмена и проверка некорректных параметров.
- Разрушение: контраст меняет внутренние цвета, сохраняя форму и внешнюю окраску; наследование материалов; повторное пересоздание не увеличивает число старых мешей и пустых клипов; внешние экземпляры сохраняют используемые меши; ширина швов не сдвигает центры и не меняет исходник.
- Рендер: отмена не выдаёт частичное дерево лучей; нормали при неравномерном масштабе; устаревшая задача завершается до запуска новой; ошибка не создаёт бесконечные повторы; разорванный канал корректно освобождается. Существующие проверки обхода дерева проверяют диапазоны листьев после перестановки треугольников в одном массиве.
- Проект: сохранение и чтение параметров разрезов; миграция схемы 26 в 27 без перезаписи входного файла; отклонение NaN, бесконечности и неверных диапазонов.
